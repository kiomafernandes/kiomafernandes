# Hallo World! 👋🤓

## Sobre mim
Profissional desenvolvedor Fullstack com conhecimento em desenvolvimento de sistemas. Entrei para a área da tecnologia através do curso de Análise e Desenvolvimento de Sistemas, onde me aprofundei em desenvolvimento fullstack. Durante o período em que cursava criei alguns projetos como freelancer para atender uma pequena demanda.

Durante minha trajetória, desenvolvi competências em backend Node.js, Typescript, Tailwind, Python, Java, Express, React Native, MySQL, PostegreSQL e frontend React.js, Tailwind, Javascript, Next.js. Sou dedicado ao aprimoramento contínuo e à colaboração em ambientes desafiadores e inovadores.
